# راهنمای اتصال فرانت‌اند و بک‌اند (Integration Guide)

این سند شامل جزئیات نحوه اتصال بخش فرانت‌اند (Next.js) به بک‌اند (Express/Prisma) و تنظیمات دیتابیس ابری است.

## ۱. تنظیمات دیتابیس ابری (Neon)
برای جلوگیری از وابستگی به دیتابیس لوکال، از دیتابیس PostgreSQL ابری (Neon) استفاده شده است.
- **محل قرارگیری آدرس:** فایل `.env` در پوشه `backend`
- **متغیر:** `DATABASE_URL` (شامل آدرس اتصال به Neon و پسورد)
- **وضعیت:** دیتابیس به صورت خودکار توسط Prisma مدیریت می‌شود و داده‌ها پایدار (Persistent) هستند.

## ۲. تنظیمات CORS در بک‌اند
برای اینکه فرانت‌اند (که روی پورت ۳۰۰۰ اجرا می‌شود) بتواند به بک‌اند (که روی پورت ۴۰۰۰ است) متصل شود، تنظیمات CORS در فایل `backend/src/app.ts` به صورت زیر پیاده‌سازی شده است:
```typescript
app.use(cors({ origin: process.env.FRONTEND_URL || 'http://localhost:3000' }));
