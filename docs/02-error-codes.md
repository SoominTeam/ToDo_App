# کدهای خطای استاندارد (Error Codes)

سرور مستقل از زبان است و فقط کد خطا برمی‌گرداند. ترجمه به فارسی یا انگلیسی در سمت فرانت‌اند انجام می‌شود.

| کد HTTP | کد خطا (Error Code) | شرایط بروز خطا |
| :---: | :--- | :--- |
| 400 | `TITLE_REQUIRED` | عنوان ارسال نشده، خالی است یا فقط از فاصله تشکیل شده است. |
| 400 | `TITLE_TOO_LONG` | طول عنوان پس از trim شدن، بیش از ۱۰۰ کاراکتر است. |
| 400 | `INVALID_INPUT` | نوع داده نادرست است (مثلاً عنوان عدد باشد)، توضیحات بیش از ۵۰۰ کاراکتر است، ساختار JSON خراب است، `id` مسیر یک عدد صحیح مثبت نیست، یا `status` یکی از `TODO`، `DONE`، `EXPIRED` نیست. |
| 404 | `TASK_NOT_FOUND` | وظیفه‌ای با `id` داده‌شده وجود ندارد (در `PATCH /api/tasks/:id/status`، `PUT /api/tasks/:id` یا `DELETE /api/tasks/:id`). |
| 500 | `SERVER_ERROR` | خطای غیرمنتظره در سرور رخ داده است. |

---

## تفکیک بر اساس Endpoint (اسپرینت دوم)

### `POST /api/tasks`
| کد HTTP | کد خطا | شرایط |
| :---: | :--- | :--- |
| 400 | `TITLE_REQUIRED` | عنوان ارسال نشده، خالی یا فقط فاصله |
| 400 | `TITLE_TOO_LONG` | عنوان بیش از ۱۰۰ کاراکتر |
| 400 | `INVALID_INPUT` | نوع داده نادرست، توضیحات > ۵۰۰ کاراکتر، JSON خراب |
| 500 | `SERVER_ERROR` | خطای غیرمنتظره |

### `PATCH /api/tasks/:id/status`
| کد HTTP | کد خطا | شرایط |
| :---: | :--- | :--- |
| 400 | `INVALID_INPUT` | `id` عدد صحیح مثبت نیست، یا `status` معتبر نیست |
| 404 | `TASK_NOT_FOUND` | وظیفه وجود ندارد |
| 500 | `SERVER_ERROR` | خطای غیرمنتظره |

### `PUT /api/tasks/:id` (جدید در اسپرینت ۲)
| کد HTTP | کد خطا | شرایط |
| :---: | :--- | :--- |
| 400 | `TITLE_REQUIRED` | عنوان ارسال نشده، خالی یا فقط فاصله |
| 400 | `TITLE_TOO_LONG` | عنوان بیش از ۱۰۰ کاراکتر |
| 400 | `INVALID_INPUT` | نوع داده نادرست، توضیحات > ۵۰۰ کاراکتر، `id` نامعتبر، JSON خراب |
| 404 | `TASK_NOT_FOUND` | وظیفه با این `id` وجود ندارد |
| 500 | `SERVER_ERROR` | خطای غیرمنتظره |

### `DELETE /api/tasks/:id` (جدید در اسپرینت ۲)
| کد HTTP | کد خطا | شرایط |
| :---: | :--- | :--- |
| 400 | `INVALID_INPUT` | `id` عدد صحیح مثبت نیست |
| 404 | `TASK_NOT_FOUND` | وظیفه با این `id` وجود ندارد |
| 500 | `SERVER_ERROR` | خطای غیرمنتظره |

## قواعد عمومی

- اگر چند خطای اعتبارسنجی همزمان باشد، فقط **اولین** خطا برگردانده می‌شود.
- **ترتیب اعتبارسنجی** در `PATCH /status`، `PUT` و `DELETE`:
  1. اعتبارسنجی `id` (params) → `400 INVALID_INPUT`
  2. اعتبارسنجی `body` (در `PUT` و `PATCH`)
  3. بررسی وجود رکورد در دیتابیس → `404 TASK_NOT_FOUND`
- در `DELETE` هیچ بدنه‌ای ارسال نمی‌شود.
- ترجمه‌ی کدهای خطا در فرانت‌اند از کلیدهای `errors.<CODE>` در `messages/fa.json` و `messages/en.json` خوانده می‌شود.
