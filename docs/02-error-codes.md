# کدهای خطای استاندارد (Error Codes)

سرور مستقل از زبان است و فقط کد خطا برمی‌گرداند. ترجمه به فارسی یا انگلیسی در سمت فرانت‌اند انجام می‌شود.

| کد HTTP | کد خطا (Error Code) | شرایط بروز خطا                                                                                                                                                                        |
| ------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 400     | `TITLE_REQUIRED`    | عنوان ارسال نشده، خالی است یا فقط از فاصله تشکیل شده است.                                                                                                                             |
| 400     | `TITLE_TOO_LONG`    | طول عنوان پس از trim شدن، بیش از ۱۰۰ کاراکتر است.                                                                                                                                     |
| 400     | `INVALID_INPUT`     | نوع داده نادرست است (مثلاً عنوان عدد باشد)، توضیحات بیش از ۵۰۰ کاراکتر است، ساختار JSON خراب است، `id` مسیر یک عدد صحیح مثبت نیست، یا `status` یکی از `TODO`، `DONE`، `EXPIRED` نیست. |
| 404     | `TASK_NOT_FOUND`    | وظیفه‌ای با `id` داده‌شده وجود ندارد (در `PATCH /api/tasks/:id/status`).                                                                                                              |
| 500     | `SERVER_ERROR`      | خطای غیرمنتظره در سرور رخ داده است.                                                                                                                                                   |
