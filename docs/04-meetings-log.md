# گزارش جلسات هماهنگی (Meetings Log)

## اسپرینت اول

- **جلسه ۱ (پایان فاز ۰):** تعیین قرارداد API و کدهای خطا.
- **جلسه ۲ (پایان فاز ۱):** راه‌اندازی دیتابیس Neon و Prisma 6.
- **جلسه ۳ (وسط فاز ۲):** هماهنگی کدهای خطا (`TITLE_REQUIRED`) و رفع خطاهای TypeScript در Zod.
- **جلسه ۴ (پایان فاز ۳):** تست موفقیت‌آمیز اتصال فرانت و بک و مشاهده داده‌ها در Neon.

## اسپرینت دوم

- **جلسه ۵ (پایان فاز ۰ — برنامه‌ریزی):** مرور بازخوردهای اسپرینت ۱، به‌روزرسانی Product Backlog، نهایی‌سازی قرارداد API برای `PUT /api/tasks/:id` و `DELETE /api/tasks/:id`، و تعیین اقدام اصلاحی «قفل کردن نسخه‌ها + مستندسازی قبل از کدنویسی».
- **جلسه ۶ (پایان فاز ۱ — فرانت‌اند):** پیاده‌سازی `StatusDropdown`، `EditTaskModal` و `DeleteTaskModal`؛ توافق بر به‌روزرسانی `createdAt` در ویرایش؛ هماهنگی نام متدهای `updateTask` و `deleteTask` در `lib/api.ts`.
- **جلسه ۷ (وسط فاز ۲ — بک‌اند):** افزودن `updateTaskSchema`، پیاده‌سازی کنترلرهای `updateTask` و `deleteTask`، و اتصال روت‌های `PUT /:id` و `DELETE /:id`. بررسی Hard Delete و حذف کامل از PostgreSQL.
- **جلسه ۸ (پایان فاز ۳ — تست و تحویل):** تست دستی سه سناریو (ویرایش، حذف، بازگشت تسک حذف‌شده) با cURL، تست پایداری داده پس از ری‌استارت سرور، و تأیید عدم تخریب مسیرهای اسپرینت ۱.
